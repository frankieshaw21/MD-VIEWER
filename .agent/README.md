# 项目上下文入口

`.agent/` 是 MD Viewer 提供给 Coding Agent 的长期项目上下文，不记录聊天过程。文件名和代码标识符保持原文，说明统一使用中文。仓库已有的 `README.md`、`CONTRIBUTING.md` 与实际代码是最终依据；文档和代码不一致时以代码为准，并修正文档。

## 每次开始工作

1. 阅读本文件和 [当前工作](current-work.md)，确认分支、未提交改动与待办事项；运行 `git status -sb`，不要覆盖其他人的修改。
2. 按任务阅读 [架构](architecture.md)、[代码地图](codebase-map.md)、[开发约定](conventions.md)、[性能](performance.md)、[测试](testing.md)、[技术决策](decisions.md) 中相关部分，再核对对应源码。
3. 明确修改对象是正式应用 `md-viewer.html`、桌面宿主 `desktop/`，还是独立演示 `demo/`；不要把 Demo 的变化当作正式应用的变化。

## 每次结束工作

- 执行与修改范围相符的检查；具体命令和限制见 [测试与验证](testing.md)。区分“构建成功”“运行通过”“安装包发布成功”。
- 若产生具有长期价值的新知识，同步更新对应的 `.agent/` 文档；任务状态变化时更新 `current-work.md`。只保存可从代码或实际验证确认的事实，不确定内容标记「待确认」。
- 未经明确要求不提交、推送、创建标签或发布；交付时说明修改范围、验证结果及尚未验证的事项。
