# 输入与模式切换优化验证

## 实现范围

- 正式前端源码输入的高亮、行号刷新改为 120 ms 防抖；等待期间显示原生文字并隐藏旧覆盖层，保持编辑内容可见，避免旧高亮文字与新输入错位。组合输入期间不重建，结束后刷新。预览模式不刷新隐藏的源码层。
- 源码内容与脏标记仍同步更新；字数和大纲延后 120 ms 合并。模式/文件切换取消待执行的 UI 更新，保存直接取得当前 textarea 内容。
- 大纲条目以 DocumentFragment 一次替换；手动重建会取消待执行的重复重建。
- 预览复用同时检查文件记录身份和原始 Markdown 内容；预览编辑及 replaceDocument 使缓存失效，编辑过的源码仍正常重渲染。外观更新经 replaceDocument 同样失效。
- 当前大纲项跟踪使用与预览大纲一致的可见标题过滤，并只切换前后项的 class；大纲点击与滚动跟踪共用当前项引用。
- CSS 和正式页面资源版本参数同步更新。没有调整 VERSION，没有安装或发布。

## 运行验证

新增 `tests/performance-regression.mjs`，Node 22+ 使用内置 WebSocket 连接独立测试页面的 CDP 端点：

```text
node tests/performance-regression.mjs http://127.0.0.1:19333
node tests/performance-regression.mjs http://127.0.0.1:19332
```

运行前需启动正式页面的 Edge 或最新 WebView2 构建，指定独立用户目录及对应远程调试端口；只绑定回环地址。脚本会添加和编辑临时内存文档，不能连接用户日常会话。它不自动启动或关闭宿主，也不执行磁盘保存。性能数值无自动通过阈值。

当前正式页面 Edge headless 与本轮最新构建的桌面 WebView2 均通过：

- 未修改源码往返复用原预览 DOM；修改后重新渲染。
- 输入后内容、脏标记立即更新；等待后大纲和高亮完成更新，期间原生文字可见。
- 预览编辑立即切源码可取得修改，返回预览保留内容。
- 合成 compositionstart/input/compositionend 流程保持原生文字层，提交内容后恢复覆盖层。
- 分屏输入更新预览；更换文件和源码模式 replaceDocument 后不复用旧文档。
- 折叠/展开 details 后当前标题正确；大纲点击后只有一个 active-heading。

另通过最新桌面原生文件桥接，在专用临时 Markdown 文件上执行源码输入后立即保存、返回预览、重载，再用 Node 读取磁盘逐字比对：内容一致，保存后 modified=false。

注意：上一份复查中的折叠标题探针用了 `h2:last-of-type`，该选择器也会选中 details 内的标题，不能作为准确复现证据。本次改为明确的 `:scope > h2` 和 instant 滚动；旧源码的未过滤标题索引与大纲错配问题有代码依据，本次修复后的严格回归通过。初次本轮测试的两项失败来自上述选择器和 smooth 滚动的测试问题，已修正测试后重跑，不隐瞒为产品失败或成功。

## 性能记录（ms）

同类标题密集样本，单次测量，只统计同步调用区间；不是端到端键盘延迟、总 CPU 或 P95。延后任务的成本仍然存在；高亮并未变成增量算法。

### 最终 Edge headless

| 字符数 | 到源码 | input 派发 | 无修改回预览 | 有修改回预览 |
| --- | ---: | ---: | ---: | ---: |
| 54,000 | 277 | 0.3 | 137 | 117 |
| 270,000 | 428 | 0.6 | 498 | 677 |
| 918,000 | 1,465 | 1.1 | 2,434 | 3,253 |

此前同类样本 input 派发分别约 169、72、118 ms；现在主要 UI 重建移出输入事件，因此同步输入处理显著缩短，但不代表后续布局成本消失。

### 最终桌面 WebView2

| 字符数 | 到源码 | input 派发 | 无修改回预览 | 有修改回预览 |
| --- | ---: | ---: | ---: | ---: |
| 54,000 | 251 | 0.3 | 97 | 105 |
| 270,000 | 410 | 0.5 | 425 | 651 |
| 918,000 | 1,588 | 18.2 | 3,048 | 2,893 |

前一次桌面运行的百万字级同步输入为 2.7 ms，无修改回预览为 2,090 ms；波动明显，不声称整体模式切换稳定提速。DOM 复用由对象身份断言确认，但 textarea/预览显示变化、innerText 字数统计及大纲仍触发布局；大文档秒级阻塞尚未解决。

## 静态、构建与限制

- 全部前端 JS 与新增测试脚本通过 node --check；git diff --check 通过。
- 本轮 desktop/build.ps1 发布构建与资源校验通过，仍有既有 MSB3277 WindowsBase 引用冲突警告。
- 测试窗口/浏览器已关闭，没有提交构建输出或更改用户文档。
- 实际中文 IME、人工键盘/鼠标体验、系统剪贴板、主题与 Mermaid 组合、长时间稳定性和内存峰值未验收。
- 会话 IndexedDB 迁移、容量失败 UI、同名文件身份处理尚未实现；留作单独任务，避免扩大数据持久化风险。
