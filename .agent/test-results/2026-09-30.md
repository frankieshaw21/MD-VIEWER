## 可复现缺陷

### P1：嵌套列表转换丢失结构

输入：

```markdown
3. parent
   1. child
4. next
```

执行 `parser.htmlToMarkdown(parser.mdToHtml(input))` 后为：

```markdown
3. parent1. child
4. next
```

子列表被并入父项，二次渲染失去嵌套。影响需要 HTML 转 Markdown 的预览编辑/保存路径；纯源码未修改的模式切换用例未发现此丢失。应增加列表递归缩进序列化回归用例。

### P2：大文档切换源码耗时数秒

见上表，1,003,000 字符源码切换约 6.46 秒。需专项性能剖析及优化，不宜仅延长防抖掩盖。
